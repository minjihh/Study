## 1. 핵심 정리

### 1-1. 전이학습 용어 (keras76 docstring)
| 용어 | 뜻 | 코드에서는 |
|---|---|---|
| Pre-trained Model (사전학습 모델) | ImageNet(1000클래스, 224×224) 같은 큰 데이터로 이미 학습된 모델 | `VGG16(weights='imagenet')` |
| Feature Extraction (특징 추출) | 사전학습 모델을 **고정(동결)**해서 특징 추출기로만 사용, 위에 붙인 FC층만 학습 | `vgg16.trainable = False` |
| Fine-tuning (파인튜닝) | 사전학습 가중치에서 시작해 **일부/전체를 다시 학습** | `vgg16.trainable = True` 또는 일부 층만 True |

### 1-2. `include_top` 복습 (keras72_1)
- `include_top=True`(기본): Flatten + FC 4096 → 4096 → 1000. 입력이 **반드시 (224,224,3)**. 파라미터 138,357,544개.
- `include_top=False`: FC층이 없어지고 마지막이 `block5_pool`. **input_shape를 바꿀 수 있음**. 파라미터 14,714,688개 (= 합성곱 13층의 파라미터).
- `weights='imagenet'`은 **기본값**이라 안 써도 ImageNet 가중치가 들어옴. 랜덤 초기화를 원하면 `weights=None`.
- VGG16은 MaxPooling이 5번 → 출력 한 변 = 입력 한 변을 2로 5번 나눈 값(나머지 버림).
  - 32 → **1** (1,1,512) / 100 → **3** (3,3,512) / 150 → **4** (4,4,512) / 200 → **6** (6,6,512)

### 1-3. `trainable=False`와 가중치 개수 (keras74_1, 74_2)
```python
vgg16 = VGG16(weights='imagenet', include_top=False, input_shape=(32,32,3))
vgg16.trainable = False
model = Sequential([vgg16, Flatten(), Dense(100), Dense(10, activation='softmax')])
len(model.weights)            # 30
len(model.trainable_weights)  # 4
```
- `len(model.weights)`는 **파라미터 개수가 아니라 가중치 "텐서" 개수**. 층 하나당 `kernel`(w) + `bias`(b) = 2개.
  - VGG16(include_top=False): Conv 13층 × 2 = **26**, Dense 2층 × 2 = **4** → 합계 **30**
  - 동결했으니 학습 가능한 것은 Dense 2층의 **4개**뿐
- 파라미터 수(summary): Flatten 출력 = 1×1×512 = 512 → Dense(100): 512×100+100 = **51,300**, Dense(10): 100×10+10 = **1,010**
  → Trainable 52,310 / Non-trainable 14,714,688
- **언제 `trainable`을 바꾸나?** `compile()` **전에** 바꿔야 함. compile 후에 바꾸면 다시 compile해야 반영됨.
- pandas 표 (74_2):
  ```python
  pd.set_option('max_colwidth', None)          # 열 내용을 자르지 않고 다 보여줌
  layers = [(type(layer).__name__, layer.name, layer.trainable) for layer in model.layers]
  pd.DataFrame(layers, columns=['Layer Type','Layer Name','Layer Trainable'])
  ```
  - `type(layer).__name__` → 클래스 이름(`'Dense'`, `'Flatten'`). VGG16 통째로는 하나의 `'Functional'` 층으로 보임.
  - 출력: `Functional vgg16 False / Flatten flatten True / Dense dense True / Dense dense_1 True`

### 1-4. 부분 동결 (keras74_3, 74_4)
**74_3: Sequential 안의 Dense 한 층만 동결**
```python
model: vgg16(동결) → Flatten → Dense(100) → Dense(90) → Dense(80) → Dense(70) → Dense(10)
#  index:   0          1          2           3           4           5           6
model.layers[5].trainable = False   # Dense(70)만 동결
```
- `model.layers`는 **0번부터**. Sequential에는 InputLayer가 목록에 안 나오므로 0번 = vgg16.
- 결과: trainable 가중치 텐서 = Dense(100), (90), (80), (10)의 **8개**. Dense(70)의 80×70+70 = **5,670** 파라미터가 Non-trainable에 추가.

**74_4: VGG16 자체의 한 층만 동결**
```python
model = VGG16(weights='imagenet', include_top=False, input_shape=(32,32,3))
model.layers[11].trainable = False
```
- 함수형 모델(VGG16)의 `model.layers`에는 **InputLayer가 0번으로 들어 있음**.
  - 0 input, 1~3 block1(conv,conv,pool), 4~6 block2, 7~10 block3(conv×3, pool), **11 = block4_conv1**
- block4_conv1 파라미터: 3×3×256×512 + 512 = **1,180,160** → 이것만 Non-trainable
- 실무에서는 보통 **앞쪽(저수준 특징: 선·모서리)은 동결**, **뒤쪽(고수준 특징)만 풀어서** 파인튜닝:
  ```python
  for layer in vgg16.layers[:15]: layer.trainable = False   # block4까지 동결, block5만 학습
  ```

### 1-5. 여러 사전학습 모델 비교 (keras75, keras76)
- keras75: `keras.applications`에서 VGG, ResNet, DenseNet, Inception, MobileNet, NASNet, EfficientNet, Xception을 import하고 `len(model.weights)`/`len(model.trainable_weights)`를 출력
  - 리스트 안에서 `VGG16()` 처럼 **괄호로 호출하는 순간 모델이 생성되고 가중치를 다운로드**함 → 19개 모델을 한 번에 메모리에 올림(무겁다)
  - BatchNormalization이 있는 모델(ResNet, DenseNet 등)은 `moving_mean`, `moving_variance`가 **원래 학습 불가 가중치**라서 `trainable=True`여도 `weights` 수 ≠ `trainable_weights` 수
- keras76: 32×32 cifar에 VGG19 / ResNet50 / ResNet101 / DenseNet201 / MobileNetV2를 `include_top=False, input_shape=(32,32,3)`로 붙여서 비교
  ```python
  for model_i in model_list:
      model_i.trainable = False
      model = Sequential([model_i, GlobalAveragePooling2D(), Dense(32), Dense(16), Dense(10, activation='softmax')])
  ```
  - InceptionV3, InceptionResNetV2, EfficientNetB0는 주석 처리: "사이즈 큰 데이터는 적용가능" (InceptionV3는 최소 75×75 입력 필요)
  - `GlobalAveragePooling2D`: (H, W, C) → 채널별 평균 → (C,). Flatten보다 **파라미터가 훨씬 적음**
  - cifar10: ES patience 10, **RLR patience 1** / cifar100: ES patience 10, **RLR patience 20**, epochs 1000

### 1-7. 코드에서 눈여겨볼 점 (버그·주의)
1. **73_15 man_horse 라벨 모양 불일치**: `y.shape = (100,)` (0/1 정수)인데 one-hot 줄(`pd.get_dummies`)이 주석 처리됨. 그런데 출력층은 `Dense(2, softmax)` + `categorical_crossentropy`이고 평가에서 `np.argmax(y_test, axis=1)`을 함 → 라벨이 (N,)이라 **shape 에러**가 나는 구성. 고치려면
   - (a) `get_dummies`/`to_categorical` 주석 해제, 또는
   - (b) `loss='sparse_categorical_crossentropy'` + `y_test` argmax 제거, 또는
   - (c) `Dense(1, sigmoid)` + `binary_crossentropy` + `np.round`
2. **73_15·73_16 입력 크기 불일치**: 데이터는 `target_size=(200,200)`으로 만든 npy인데 VGG16은 `input_shape=(150,150,3)`. 입력 크기를 데이터와 맞춰 `(200,200,3)`으로 써야 함 (73_18은 200으로 맞춰 둠).
3. **스케일링**: 모든 파일이 `/255.`만 씀. ImageNet 가중치는 원래 각 모델의 `preprocess_input`(VGG는 BGR 변환 + 평균 빼기)으로 학습됐음 → `from keras.applications.vgg16 import preprocess_input`을 쓰면 성능이 더 나을 수 있음.
4. **keras76_2(cifar100)의 RLR patience 20 > ES patience 10** → val_loss가 10번 안 좋아지면 ES가 먼저 멈추므로 **ReduceLROnPlateau가 한 번도 작동하지 못함**. RLR patience는 ES보다 작게.
5. keras76의 `Dense(32)`, `Dense(16)`에 **activation이 없음** → 선형층 두 개를 쌓아도 하나의 선형층과 같은 표현력.
6. keras74_3, 74_4 맨 아래의 결과 주석은 74_2에서 **복사해 온 것이라 실제 출력과 다름**(74_3은 7줄, 74_4는 VGG16 19줄이 나옴).
7. MobileNetV2는 ImageNet 가중치가 96/128/160/192/224 입력용이라 32×32를 넣으면 **경고와 함께 224용 가중치**를 불러옴.

## 3. 정답 및 해설

### A
1. **O**

6. **O** — 역전파/가중치 갱신을 하는 파라미터가 줄어듦. (rps: 254초 vs 579초)
7. **O**
8. **O** — 76_2가 그 경우.

### B
① Feature Extraction(특징 추출) ② Fine-tuning(파인튜닝) ③ kernel(w) ④ bias(b) ⑤ `__name__` ⑥ `max_colwidth` ⑦ `GlobalAveragePooling2D` ⑧ `(None, 4, 4, 512)` (150→75→37→18→9→4)

### C
**C1.** (1) `36 8` — 전체: 26 + Dense 5층×2 = 36 / 학습 가능: Dense(100),(90),(80),(10) → 4층×2 = 8
(2) index 0 vgg16, 1 flatten, 2 dense(100), 3 dense(90), 4 dense(80), **5 dense(70)**
(3) 14,714,688 + (80×70+70 = 5,670) = **14,720,358**

**C2.** `block4_conv1 26 24` — 13개 conv 중 하나(kernel+bias 2개)만 동결.

**C3.** `30` — 26(VGG16) + 4(Dense 2층). 전부 학습 가능.

**C4.** 출력 (4,4,512)
- Flatten: 4×4×512 = 8,192 → 8,192×256 + 256 = **2,097,408**
- GAP: 512 → 512×256 + 256 = **131,328** (약 16배 적음)

### D
**D1.** 라벨이 (N,)인데 `categorical_crossentropy`는 (N, 2) one-hot을 기대 → **fit 단계에서 shape 불일치 에러**. 또 `np.argmax(y_test, axis=1)`도 1차원 배열이라 `AxisError`.
- 방법1: `y = pd.get_dummies(y, dtype=int).values` (또는 `to_categorical(y)`) 주석 해제
- 방법2: `loss='sparse_categorical_crossentropy'`, `y_test` argmax 줄 삭제
- 방법3: `Dense(1, activation='sigmoid')` + `binary_crossentropy` + `y_pred = np.round(y_pred)`

**D2.** `input_shape=(200,200,3)`으로 데이터와 맞춘다. (또는 데이터를 150으로 resize. 73_18은 200으로 맞춰져 있음)

**D3.** RLR patience(20) > ES patience(10). val_loss가 10 epoch 개선이 없으면 ES가 먼저 멈춰서 **lr 감소가 한 번도 안 일어남**. RLR patience를 ES보다 작게(예: ES 10, RLR 3~5).

```python
# E2
from keras.applications import VGG19, ResNet50
from keras.applications import vgg19, resnet50
from tensorflow.keras.datasets import cifar10
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import GlobalAveragePooling2D, Dense
from tensorflow.keras.callbacks import EarlyStopping, ReduceLROnPlateau

(x_train, y_train), (x_test, y_test) = cifar10.load_data()

pairs = [(VGG19, vgg19.preprocess_input), (ResNet50, resnet50.preprocess_input)]
results = {}
for Base, prep in pairs:
    base = Base(include_top=False, input_shape=(32, 32, 3))
    base.trainable = False
    model = Sequential([base, GlobalAveragePooling2D(),
                        Dense(32, activation='relu'), Dense(10, activation='softmax')])
    model.compile(loss='sparse_categorical_crossentropy', optimizer='adam', metrics=['acc'])
    xtr = prep(x_train.astype('float32'))   # /255 대신 모델 전용 전처리
    xte = prep(x_test.astype('float32'))
    model.fit(xtr, y_train, epochs=100, batch_size=32, validation_split=0.2, verbose=0,
              callbacks=[EarlyStopping(patience=10, restore_best_weights=True),
                         ReduceLROnPlateau(patience=3, factor=0.5)])
    results[base.name] = model.evaluate(xte, y_test, verbose=0)[1]

for name, acc in sorted(results.items(), key=lambda kv: kv[1], reverse=True):
    print(f'{name}: {acc:.4f}')
```
- 포인트: `preprocess_input`은 **모델마다 다르므로** 모델과 짝을 지어 둠 / 데이터 load는 반복문 밖으로 / RLR patience < ES patience / Dense에 activation 추가

### F (모범 답안 요지)
1. VGG16은 ImageNet 수백만 장으로 이미 **선·모서리·질감·형태 같은 일반 특징**을 배워 둠. 100장으로는 이런 특징을 처음부터 배우기 어렵지만, 동결해서 가져다 쓰면 마지막 분류층만 학습하면 되므로 **적은 데이터로도 과적합 없이** 잘 맞춤.
2. 앞쪽 층은 어떤 이미지에나 통하는 **저수준 특징**(선, 색, 모서리)이라 그대로 써도 되고, 뒤쪽 층은 ImageNet 클래스에 특화된 **고수준 특징**이라 새 데이터에 맞게 조정할 필요가 있음. 전부 풀면 파라미터가 많아 데이터가 적을 때 과적합되고 사전학습 가중치가 망가질 수 있음.
3. BatchNormalization의 `moving_mean`, `moving_variance`는 역전파로 학습하는 값이 아니라 **배치 통계로 갱신되는 non-trainable 가중치**라서, `trainable=True`여도 `trainable_weights`에 포함되지 않음. (VGG16은 BN이 없어서 두 값이 같음)
