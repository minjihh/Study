## 1. 핵심 정리 — 코드 흐름 한 번에 보기

### 1-1. m09 (XGBoost + RandomizedSearchCV) 실행 순서
```
load_digits → train_test_split(stratify=y, train_size=0.8)
            → StratifiedKFold(5, shuffle=True, random_state=333)
            → parameters (dict 3개, 18+12+12 = 42 조합)
            → RandomizedSearchCV(xgb, parameters, n_iter=10, refit=True)
            → fit(x_train) : 10 후보 × 5 fold = 50 fit  (+ refit 1)
            → best_params_ / best_estimator_ / best_score_ (train CV)
            → model.score(x_test) (진짜 성능)
```
- `verbose=1` 이면 실행 시 `Fitting 5 folds for each of 10 candidates, totalling 50 fits` 가 출력됩니다 → 이 문장으로 fit 횟수를 바로 확인할 수 있습니다.
- `time.perf_counter()` : 경과시간 측정용 고해상도 타이머 (`end - start` = 초).

### 1-2. dict 리스트 vs 확률분포
- 수업 코드는 **리스트(이산값)** 만 사용 → 후보가 유한(42개).
- RandomizedSearchCV의 진짜 장점은 `scipy.stats` **분포**를 넣을 수 있다는 것:
  ```python
  from scipy.stats import loguniform, randint
  {'learning_rate': loguniform(1e-3, 1e-1), 'max_depth': randint(3, 13)}
  ```
  → 0.001~0.1 사이의 아무 값이나 뽑음. GridSearch는 분포를 받을 수 없음.

### 1-3. 결과 꺼내보기: `cv_results_`
- 모든 후보의 점수를 담은 dict. `pd.DataFrame(model.cv_results_)` 로 보면 편함.
- 주요 컬럼: `params`, `mean_test_score`, `std_test_score`, `rank_test_score`, `split0_test_score`…, `mean_fit_time`.
- ⚠️ 이름이 `test_score`지만 **CV 검증 fold 점수**입니다 (x_test 점수 아님).
- `best_index_` → `cv_results_`에서 1등 행의 인덱스.

### 1-4. `scoring` 인자
- 생략하면 모델의 기본 `score` 사용: 분류 → accuracy, XGBRegressor → R², KerasRegressor(구버전) → -loss.
- 회귀에서 오차 지표로 고르고 싶으면 `scoring='neg_mean_squared_error'` 처럼 **neg_** 가 붙은 이름 사용(크면 좋다 규칙).

### 1-5. keras77 구조 다시 보기
- `Input(10)` → hidden1~3 (각각 뒤에 `Dropout(drop)`) → hidden4 → hidden5 → `Dense(1, linear)`.
  - Dropout은 **hidden1~3 뒤에만** 있음 (4, 5 뒤에는 없음).
- 같은 `activation`이 hidden1~5 전부에 적용됨 (층마다 다르게 하려면 인자를 나눠야 함).
- `n_jobs=1` + `verbose=1`(래퍼) + `verbose=1`(Search) + `verbose=1`(fit) → 로그가 매우 길게 출력됨.

## 3. 정답 및 해설

1. `RandomizedSearchCV`, `-1`, `best_params_`, `x_test, y_test`
2. `Fitting 5 folds for each of 10 candidates, totalling 50 fits`
3. `Fitting 3 folds for each of 10 candidates, totalling 30 fits` (refit 1번은 로그에 포함 안 됨)
4. 예시:
   ```python
   from sklearn.model_selection import KFold
   kfold = KFold(n_splits=5, shuffle=True, random_state=333)   # ① StratifiedKFold → KFold
   model = RandomizedSearchCV(xgb, parameters, cv=kfold, verbose=1, n_jobs=-1,
                              random_state=333, refit=True)    # ② refit=True
   model.fit(x_train, y_train)
   print("최적의 파라미터 :", model.best_params_)               # ③ 주석 해제
   print("model.score(R2) :", model.score(x_test, y_test))
   print("best_score :", model.best_score_)
   ```
   (+ 안 쓰는 `HistGradientBoostingClassifier`, `accuracy_score` import는 지워도 됨)
5. ```python
   import pandas as pd
   df = pd.DataFrame(model.cv_results_)
   print(df.sort_values('rank_test_score')[['params', 'mean_test_score']].head(3))
   ```
6. ```python
   from scipy.stats import randint, loguniform
   {'n_estimators': randint(100, 501),          # 상한 미포함이라 501
    'max_depth': [6, 10, 12],
    'learning_rate': loguniform(1e-3, 1e-1)}
   ```
   (분포가 섞인 dict가 있으면 n_iter개를 그 분포에서 샘플링)
7. ```python
   best = XGBClassifier(**model.best_params_)
   best.fit(x_train, y_train)
   print(best.score(x_test, y_test))
   ```
   `**dict` 언패킹으로 파라미터를 그대로 넘김 = refit=True가 내부에서 하는 일과 같음.
8. CV에서 **검증으로 쓴 fold**에 대한 점수(train 데이터의 일부). `model.score(x_test, y_test)`는 탐색에 한 번도 쓰이지 않은 진짜 test 데이터 점수.
9. sklearn은 "점수가 클수록 좋다"로 비교하므로 MSE에 마이너스를 붙임(neg_). MSE = **3100**.
10. 분포는 값이 무한(연속)하므로 "전체 조합 수"를 셀 수 없음 → 경고 대상이 아님. (모든 파라미터가 리스트일 때만 조합 수 비교 후 경고)
11. hidden1, hidden2, hidden3 뒤에 **3개**. hidden4, hidden5 뒤에는 없음. (참고: selu는 원래 `AlphaDropout`과 함께 쓰는 게 권장됨)
12. `random_state`는 **어떤 후보 10개를 뽑을지**만 고정. 신경망 가중치 초기화·Dropout·validation_split 셔플 등의 랜덤성은 TF 쪽 시드(`tf.random.set_seed`)를 따로 고정해야 같아짐. 또 `cv=3`(정수)은 셔플 없는 KFold라 fold 자체는 고정.
13. `refit`의 **기본값이 True**라서. 명시해 두면 코드를 읽는 사람이 의도를 바로 알 수 있다는 장점만 있음.
14. 예: "GridSearchCV는 정해 둔 파라미터 조합을 전부 교차검증해 최고를 고른다. 조합이 너무 많으면 RandomizedSearchCV로 n_iter개만 무작위로 뽑아 시간을 줄인다. Keras 모델은 KerasRegressor로 sklearn 모델처럼 포장하면 같은 방식으로 batch_size·노드 수·optimizer까지 탐색할 수 있다."
15. ① KerasRegressor의 score = **-loss** ② `scoring='neg_mean_squared_error'` 처럼 오차 지표에 neg_ 접두어. (+ `rank_test_score` 1등 = mean_test_score가 가장 큰 후보)
