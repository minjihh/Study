## 1. 핵심 정리

### 1-1. GridSearchCV vs RandomizedSearchCV
| | GridSearchCV | RandomizedSearchCV |
|---|---|---|
| 탐색 | 모든 조합 전부 | 조합 중 `n_iter`개만 무작위 선택 |
| 비용 | 조합 수 × cv 만큼 학습 | `n_iter` × cv 만큼 학습 (기본 `n_iter=10`) |
| 재현성 | 항상 동일 | `random_state` 지정해야 동일 |

- 코드의 `parameters`는 dict 3개짜리 리스트 → 조합 수 `18 + 12 + 12 = 42`.
- Grid는 42 × 5fold = 210번 학습, Random(n_iter=10)은 10 × 5 = 50번 학습 → **시간 절약**, 대신 최적 조합을 놓칠 수 있음.
- 리스트 안의 dict들은 서로 "OR" 관계: 한 dict 안의 파라미터끼리만 조합됨.

### 1-2. 주요 인자
- `cv=kfold` : 교차검증 방식 (`StratifiedKFold`는 **분류**용, 클래스 비율 유지).
- `n_jobs=-1` : 모든 CPU 코어 사용.
- `verbose=1` : 진행 로그 출력.
- `refit=True`(기본) : 탐색 후 **best 파라미터로 전체 train 데이터에 다시 학습** → `best_estimator_`, `predict`, `score` 사용 가능.
- `refit=False` : 재학습 안 함 → `best_estimator_`, `score()`, `predict()` 사용 불가 (`best_params_`, `best_score_`는 가능). 02_diabetes에서 관련 print가 주석 처리된 이유.
- `best_score_` : CV(train 내부)에서의 최고 평균 점수 → 테스트 점수가 아니므로 과적합 가능성 있음. 진짜 성능은 `model.score(x_test, y_test)`.

### 1-3. digits(분류) vs diabetes(회귀)
- digits: `XGBClassifier`, `stratify=y`, `StratifiedKFold`.
- diabetes: `XGBRegressor`, `stratify` 주석처리(연속값 타깃이라 불가).
- ⚠️ **02_diabetes 코드 주의**: 회귀인데 `cv=StratifiedKFold`를 쓰고 있음 → 타깃이 연속값이라 실행 시 에러(`Supported target types are: binary, multiclass`)가 날 수 있음. 회귀는 `KFold` 사용.
- 참고: 두 파일에 `HistGradientBoostingClassifier`, `accuracy_score`, `numpy`는 import만 하고 사용 안 함.

### 1-4. keras77: Keras 모델 + RandomizedSearchCV
- `build_model(...)`: 하이퍼파라미터(drop, optimizer, activation, node1~5)를 인자로 받아 모델을 만드는 **함수형 API 모델 생성 함수**.
- `create_heyperparameter()`: 탐색할 값들을 dict로 반환. `batch_size`도 포함.
- `KerasRegressor(build_fn=build_model)`: Keras 모델을 sklearn 추정기처럼 감싸는 **래퍼**. 그래야 `RandomizedSearchCV`에 넣을 수 있음. (`build_fn`이 모델 생성 함수)
- `batch_size`는 `build_model` 인자가 아니라 `fit`에 전달되는 값 (래퍼가 처리).
- `model.fit(..., callbacks=[es, rlr], validation_split=0.1)` : EarlyStopping(patience 10, 최적 가중치 복원) + ReduceLROnPlateau(patience 8, factor 0.8).
- 탐색 횟수: `n_iter=10 × cv=3 = 30번` 학습 (+ refit 1번).
- ⚠️ `build_model`의 `lr` 인자는 `compile`에서 사용되지 않음 (optimizer 문자열만 사용 → 학습률 조절 안 됨).
- ⚠️ `tensorflow.keras.wrappers.scikit_learn`은 최신 TF(2.12+)에서 제거됨 → `scikeras.wrappers.KerasRegressor` 사용 필요.
- 회귀 모델: 출력층 `Dense(1, activation='linear')`, `loss='mse'`, `metrics=['mae']`.
