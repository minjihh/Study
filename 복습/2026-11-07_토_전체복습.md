# Part B. 레포 전체 요약

## B-1. keras/ (기초 → CNN → RNN)
- **기본 4단계**: 1.데이터 → 2.모델구성 → 3.컴파일·훈련 → 4.평가·예측. 회귀: `linear + mse` / 이진분류: `sigmoid + binary_crossentropy` / 다중분류: `softmax + categorical_crossentropy`(ohe) 또는 `sparse_categorical_crossentropy`(ohe 불필요).
- **데이터 분할**: `train_test_split`, `validation_split`, `validation_data`. 회귀엔 `stratify` ❌.
- **평가 지표**: R2, RMSE, accuracy(`metrics=['acc']`).
- **과적합 대응**: `EarlyStopping`(monitor, mode, patience, restore_best_weights), `Dropout`, `ReduceLROnPlateau`, 데이터 증강.
- **스케일러**: Minmax / Standard / MaxAbs / Robust(이상치에 강함). **train에만 fit**, test는 transform. 이미지(0~255)는 `/255.` 또는 `(x-127.5)/127.5`.
- **저장**: `model.save`, `save_weights`, `ModelCheckpoint(save_best_only=True)`.
- **함수형 모델**: `Input → Dense(...)(x) → Model(inputs, outputs)`.
- **차원 규칙** (`모델종류.txt`): DNN=2D, RNN=3D, CNN=4D / Dense `input_shape`=1개, Conv2D=3개(h,w,c), RNN=2개(timesteps, feature).
- **CNN**: `Conv2D(filters, kernel, strides, padding)`, `same`=크기 유지, `valid`=줄어듦. `MaxPooling2D`로 축소, `GlobalAveragePooling2D`는 Flatten 대체. Conv 파라미터 = `filters × (kh×kw×in_ch + 1)`.
- **ImageDataGenerator**: `flow_from_directory`, 증강(flip/shift/rotation/zoom/shear), test는 `rescale`만, test는 `shuffle=False`. 이미지 → `.npy`로 저장 후 load하면 빠름.
- **옵티마이저**: `Adam`, `ReduceLROnPlateau(factor, patience)`.
- **RNN/LSTM**: 입력 `(samples, timesteps, features)`. SimpleRNN 파라미터 = `units×(features+units+1)`. `return_sequences=True`면 3D 출력(RNN을 쌓을 때). `Bidirectional`은 파라미터 2배. 시계열 `split_x`로 윈도우 만들기. (jena 데이터)

## B-2. keras2/ (NLP · 전이학습 · 앙상블)
- **Tokenizer**: `fit_on_texts` → `word_index`(1부터, 빈도순), `texts_to_sequences` → `pad_sequences(padding, maxlen)`로 길이 맞춤.
- **Embedding**: 정수 → 밀집 벡터. 입력 2D, 출력 3D. `Embedding(단어사전크기, output_dim)`. 원핫보다 차원이 작고 유사도 계산 가능.
- 데이터: reuters, imdb. `sparse_categorical_crossentropy`로 ohe 생략.
- **Reshape / Conv1D**: 레이어 사이에서 차원 변환, 시계열에 Conv1D.
- **앙상블(여러 입력 모델)**: 모델별 Input → 각각 Dense → `concatenate` → 출력. `train_test_split`에 여러 x를 한번에 넣을 수 있음.
- **전이학습**: `VGG16(weights='imagenet', include_top=False, input_shape=...)`. `trainable=False`로 동결(weights 개수는 유지, trainable_weights만 0). 일부 층만 동결 = `model.layers[i].trainable = False`.
- `keras75/76`: 다양한 pretrained 모델(Xception 등)을 cifar10/100에 적용.

## B-3. ml/ (전통 ML)
- **feature_importances_**: tree 계열(DecisionTree, RandomForest, GradientBoosting, XGB). XGB는 gain 기준 시각화 가능.
- **KFold / StratifiedKFold** + `cross_val_score`(분류=acc, 회귀=R2), `cross_val_predict`.
- 순서: **train/test 분리 → train에만 KFold** (m03).
- `all_estimators`로 전체 모델 비교 (m04~m06).
- 튜닝: for문(m07) → GridSearchCV(m08).

## B-4. RAG/ (OpenAI 호환 API + LangChain)
- **RAG** = Retrieval(검색) + Augmented(질문에 자료 붙임) + Generation(근거 기반 생성).
- API 키는 `.env` + `load_dotenv()` + `os.environ[...]`. base_url을 따로 지정.
- **LCEL**: `chain = prompt | model | output_parser`, `chain.invoke({...})`.
- **문서 파이프라인**: Loader(`TextLoader`, `PyPDFLoader`) → `RecursiveCharacterTextSplitter(chunk_size, chunk_overlap, separators)` → Embedding → VectorDB.
  - `chunk_overlap < chunk_size`. 
- **Embedding**: OpenAI `text-embedding-3-small`(1536차원)/`large`(3072), HuggingFace `BAAI/bge-m3`(1024차원), `Qwen3-Embedding-0.6B`.
- **VectorDB** (`VectorDB.txt`): Chroma = 벡터 + 원문 + 메타데이터 + 추가/수정/삭제(collection). FAISS = 벡터 검색 속도 특화(원문은 별도 관리), 유클리드 거리 기반.
- `Chroma.from_documents(persist_directory, collection_name)` 재실행 시 **계속 누적됨**.
- **Gradio 챗봇**: history, 유사도 점수 확인, 프롬프트 템플릿.
- **검색 방식**: BM25(키워드) / 벡터(의미) / **하이브리드(Ensemble)** = 둘을 가중 결합.

## B-5. LG/ (LangGraph)
- **TypedDict**: 타입 힌트일 뿐 런타임 강제 ❌.
- LangGraph 3요소: **State / Node / Edge**. `Annotated[list, add_messages]`의 `add_messages`가 **reducer**(append, 같은 id면 덮어쓰기).
- 순서: State 정의 → node 정의 → `StateGraph(State)` → `add_node` → `add_edge(START,...)` → `compile()` → `invoke()`.
- **Tool calling**: `llm.bind_tools(tools)`, `ToolNode`, `tools_condition`(도구 호출 필요하면 tools로, 아니면 END). Tavily 웹 검색, DuckDuckGo.
- **Memory**: checkpointer + `thread_id`로 대화 이어가기.
- **병렬 실행/병합**: `START → search`, `START → analysis` 두 엣지 → 둘 다 `merge`로 연결(lg09).
