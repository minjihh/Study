## 1. 핵심 정리

### 1-1. 공통 뼈대
모든 파일이 같은 구조예요.
```python
x = np.arange(-5, 5, 0.1)   # -5.0 ~ 4.9, 원소 100개 (5는 포함 안 됨)
y = 함수(x)                  # numpy 배열 전체에 한 번에 적용 (벡터 연산)
plt.plot(x, y); plt.grid(); plt.show()
```
- `def f(x): return ...` 와 `f = lambda x: ...` 는 **완전히 같은 동작**. 파일마다 `def`를 주석 처리하고 lambda로 바꿔 쓰는 연습을 함.
- `keras78_04_SiLu.py`는 `def silu`를 만든 뒤 **같은 이름**으로 lambda를 다시 대입함 → 마지막에 대입된 lambda가 사용됨 (이름 덮어쓰기).

### 1-2. 함수별 한눈 정리

| 파일 | 함수 | 식 | 출력 범위 | 기억할 점 |
|---|---|---|---|---|
| 01 | sigmoid | `1/(1+e^-x)` | (0, 1) | σ(0)=0.5. 이진분류 출력층. 양 끝에서 기울기 → 0 (기울기 소실) |
| 02 | tanh | `np.tanh(x)` | (-1, 1) | 0을 중심으로 대칭. tanh(0)=0 |
| 03 | relu | `np.maximum(0, x)` | [0, ∞) | 음수는 전부 0 → 죽은 뉴런(dying ReLU) 문제 |
| 04 | silu (swish) | `x * sigmoid(x)` | 약 [-0.278, ∞) | 음수 쪽도 0이 아니라 살짝 아래로 내려갔다 0으로 돌아옴 |
| 05 | mish | `x * tanh(ln(1+e^x))` | 약 [-0.31, ∞) | `ln(1+e^x)` = softplus. 연산량이 silu보다 많음 |
| 06 | elu | `x` (x>0), `α(e^x-1)` (x<0) | (-α, ∞) | 음수 쪽 하한을 α로 조정 |
| 07 | selu | `λ * elu(x, α)` (고정 α, λ) | (-λα≈-1.758, ∞) | α≈1.6733, λ≈1.0507 **논문 고정값** (자기 정규화) |
| 08 | leaky_relu | `np.where(x>0, x, 0.01x)` | (-∞, ∞) | 음수에 아주 작은 기울기(0.01)를 남겨 dying ReLU 완화 |
| 09 | softmax | `e^x / Σe^x` | (0,1), 합=1 | 다중분류 출력층. 지수 때문에 큰 값은 더 크게 |

### 1-3. 코드에서 쓰인 numpy 트릭
- **불리언 곱셈으로 if문 대신하기** (elu, selu):
  `(x>0)*x + (x<0)*(...)` → `True=1`, `False=0` 으로 계산되어 조건에 맞는 항만 남음.
- **`np.where(조건, 참일때, 거짓일때)`** (leaky_relu): 원소별 if-else.
- `np.maximum(0, x)` 는 원소별 최대값 (`np.max`와 다름! `np.max`는 배열 전체의 최댓값 하나).

### 1-4. 코드 주석 보충 / 주의할 점
1. **elu vs selu의 경계 처리가 다름**
   - elu(06): `(x>0)*x + (x<0)*(...)` → x가 정확히 0이면 두 항 모두 0 → 결과 0 (문제 없음)
   - selu(07): `(x<=0)` 사용 → x=0이면 `α(e^0-1)=0` → 역시 0. 결과는 같지만 **쓰는 방식이 다름**을 알아두기.
2. **`np.arange(-5, 5, 0.1)` 의 51번째 값(`x[50]`)은 정확히 0이 아님**
   실제 값은 `-1.78e-14` 정도의 아주 작은 음수 (부동소수점 오차). 그래프에는 영향 없음.
3. **`keras78_09_softmax.py` 의 `plt.pie(ratio, labels, ...)`**
   `plt.pie`의 **두 번째 위치 인자는 `labels`가 아니라 `explode`**(조각을 중심에서 띄우는 거리)입니다.
   그래서 이 코드는 라벨이 붙는 대신 조각이 y값만큼 튀어나와 보여요.
   라벨을 붙이려면 `plt.pie(ratio, labels=labels, ...)` 처럼 **키워드로** 넘겨야 합니다.
   (또 `labels`에 float 배열을 그대로 넣기보다 `[f'{v:.3f}' for v in y]` 같은 문자열이 깔끔해요.)
4. **softmax 오버플로**: `np.exp(1000)` → `inf` → `inf/inf = nan`.
   실무에선 `np.exp(x - np.max(x))` 로 최댓값을 빼고 계산 (결과는 수학적으로 동일).
5. `keras78_01` 상단 주석 "마지막 층의 activation은 relu 사용하지 않음"
   → 회귀는 보통 `linear`, 이진분류 `sigmoid`, 다중분류 `softmax`. (출력이 항상 0 이상인 회귀라면 relu도 쓸 수는 있음)

### A. 코드 읽기

- **A2.** `lambda` 쪽. 파이썬은 위에서 아래로 실행되고, 같은 이름 `silu`에 lambda가 **나중에 다시 대입**되었기 때문. (`def`로 만든 함수 객체는 더 이상 그 이름으로 접근 불가)

- **A4.** `np.max(a, axis)` 의 두 번째 인자는 **axis** 입니다. `np.max(0, x)` 는 "숫자 0의 최댓값을 x축 기준으로" 라는 뜻이 되어 에러. 원소별 비교는 `np.maximum`.

### B. 손계산
- **B1.**
  ① σ(-1) ≈ **0.269**  ② **0**  ③ silu(-1) = -1 × 0.269 = **-0.269**  ④ 0.01 × (-1) = **-0.010**
  ⑤ elu(-1) = 1 × (e⁻¹ - 1) = 0.368 - 1 = **-0.632**  ⑥ σ(0) = **0.5**  ⑦ 0 × 0.5 = **0**
  ⑧ σ(2) ≈ **0.881**  ⑨ silu(2) = 2 × 0.881 = **1.762**
- **B2.** x>0 이므로 λ·x = 1.0507 × 2 ≈ **2.101**
- **B3.** λ·α·(0 - 1) = -1.0507 × 1.6733 ≈ **-1.758**
- **B4.** -1 → **-2** 로 내려감 (하한 = -α). 파일 주석의 "음수 부분 하한값을 alpha로 조정"이 바로 이 뜻.
- **B5.** 4번째 원소(값 4)가 최대, 약 **64.4%** (실제 값 `[0.032, 0.087, 0.237, 0.644]`). 합은 **1**.
  → 원래 값 1:4 차이가 확률에서는 약 0.032:0.644 = 1:20 차이가 됨. 이게 "큰 숫자는 더 크게, 작은 숫자는 더 작게"(09 파일 주석)의 의미.

### C. 개념
- **C1.** σ'(x) 최댓값은 x=0에서 0.5×0.5 = **0.25**. 역전파 때 층마다 ≤0.25 가 곱해지므로 층이 깊어질수록 기울기가 0에 가까워짐 → **기울기 소실(vanishing gradient)**. 그래서 은닉층은 relu 계열을 주로 씀.
- **C2.** 입력이 음수면 출력·기울기가 모두 0이 되어, 한 번 음수 영역에 빠진 뉴런은 가중치가 더 이상 업데이트되지 않는 현상. 완화: **leaky_relu, elu, selu, silu(swish), mish** (음수 쪽에도 0이 아닌 값/기울기가 있음).
- **C3.** x가 크면 sigmoid(x) → 1 이므로 silu(x) = x·σ(x) ≈ x = relu(x).
- **C4.** ① 출력 범위: sigmoid (0,1) / tanh (-1,1) ② 중심: tanh는 **0 중심(zero-centered)**, sigmoid는 0.5 중심. (tanh도 양 끝에서 기울기 소실은 있음)
- **C5.** 논문에서 "층을 지나도 출력의 평균 0, 분산 1이 유지되도록(자기 정규화)" 수학적으로 계산된 값이라서. 바꾸면 그 성질이 깨짐. (보통 `lecun_normal` 초기화와 함께 사용)
- **C6.** (a) `linear` (b) `sigmoid` (c) `softmax` (d) 각 라벨마다 독립적인 `sigmoid`
